📌 O que são descontos comerciais?

Na prática financeira, descontar um título (como uma duplicata ou nota promissória) significa antecipar seu recebimento antes da data de vencimento. Em troca dessa antecipação, o portador abre mão de uma parte do valor — essa diferença é o valor do desconto (VD). O valor efetivamente creditado ao portador é chamado de valor comercial (VC), enquanto o valor original do título é o valor nominal (FV).

No desconto simples comercial (ou desconto por fora), o desconto é sempre calculado sobre o valor nominal FV — e não sobre o valor comercial — a uma taxa i por período, durante n períodos de antecipação. Isso faz com que a taxa efetiva cobrada seja sempre maior do que a taxa nominal anunciada.

Fórmulas principais:
VD = FV · n · i   (valor do desconto)
VC = FV · (1 − n · i)   (valor comercial / líquido creditado)
FV = VC / (1 − n · i)   (valor nominal, dado VC)
n  = VD / (FV · i)   (prazo de antecipação)
i   = VD / (FV · n)   (taxa de desconto)
if = (FV / VC − 1) / n   (taxa efetiva — sempre > i)
